Khuyến Nghị Phòng Chống

  • Xác thực email: Kiểm tra kỹ Return-Path, áp dụng SPF, DKIM, DMARC.
  • Kiểm soát Endpoint (EDR): Chặn Microsoft Office tự động chạy Macro, giám sát hành vi spawn shell lạ (cmd, powershell).
  • Lọc đầu vào (Input Validation): Dùng Parameterized Queries để chống SQL Injection.
  • Kiểm soát đặc quyền (PAM): Thường xuyên kiểm tra các file có quyền SUID trên hệ thống Linux.
  • Giám sát mạng: Chặn/cảnh báo các kết nối Outbound bất thường đến IP lạ.
